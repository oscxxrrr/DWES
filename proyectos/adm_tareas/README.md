## 📌 Sobre el Proyecto

Este repositorio contiene el desarrollo de una aplicación web de **gestión de tareas (Task Manager)** desarrollada en **PHP** y **MySQL** --> Grado Superior en Desarrollo de Aplicaciones Web (DAW) en el **I.E.S. Politécnico Hermenegildo Lanz**.

El proyecto está enfocado en la implementación de la lógica del lado del servidor, la persistencia de datos mediante bases de datos relacionales y la realización de operaciones **CRUD** completas.

## 📂 Funcionalidades y Operaciones Implementadas

La aplicación cubre los flujos fundamentales para la administración y control de tareas:

- **Conexión a Base de Datos:** Establecimiento de conexión segura con MySQL/MariaDB para la persistencia de la información.
- **Consulta de Datos:** Listado y visualización dinámica de las tareas registradas en el sistema.
- **Inserción de Tareas:** Formularios y scripts en PHP para registrar nuevas tareas en la base de datos.
- **Eliminación y Actualización:** Mecanismos para borrar registros existentes o modificar su estado.
