## 📌 Sobre el Repositorio

Este repositorio contiene la recopilación de **ejercicios prácticos, scripts y aplicaciones web dinámicas en PHP** desarrolladas durante el segundo curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW) en el **I.E.S. Politécnico Hermenegildo Lanz**.

El objetivo de este espacio es afianzar la lógica de backend, la conexión y gestión de bases de datos relacionales, el manejo de sesiones, la seguridad y la arquitectura web del lado del servidor utilizando un entorno optimizado con **WSL** y **Docker**.

## 📂 Contenido y Prácticas

El código está estructurado para abordar diferentes conceptos clave del desarrollo en entorno servidor:

- **Sintaxis y Estructuras de Control:** Formularios, validaciones, paso de parámetros por GET y POST.
- **Programación Orientada a Objetos (POO):** Clases, objetos, herencia y espacios de nombres (*namespaces*).
- **Persistencia y Bases de Datos:** Conexión mediante PDO, consultas preparadas, operaciones CRUD y gestión de bases de datos relacionales.
- **Sesiones y Autenticación:** Control de acceso, login de usuarios, roles y seguridad en aplicaciones web.
